# COURS-B2

## Description

Ce dépôt contient l'ensemble des cours, supports théoriques et prises de notes personnels accumulés tout au long de mon cursus de Bachelor 2 (B2). Il sert d'archive centrale pour mes révisions et travaux pratiques.

## 📂 Contenu et Structure

Le dépôt est organisé par matières, chacune disposant de son propre dossier. Voici les différents modules couverts :

### Développement
* **📂 C#** : Cours et travaux pratiques sur le langage C#.
* **📂 JAVA** : Supports de cours et projets en Java.
* **📂 Python** : Scripting et développements en langage Python.
* **📂 Scripting** : Automatisation et scripts divers (ex: Bash).
* **📂 FRAMEWORK JS** : Étude et utilisation de bibliothèques et frameworks JavaScript.

### Systèmes, Réseaux & Infrastructure
* **📂 Linux** : Administration et commandes système Linux.
* **📂 CISCO** : Configuration et gestion d'équipements réseaux (Cisco).
* **📂 Windows Server** : Administration de serveurs sous Windows (ex: TP DFS).
* **📂 Cloud** : Concepts et mise en pratique de technologies Cloud.

### Données & Cybersécurité
* **📂 BDD** : Base de Données (conception, SQL, NoSQL).
* **📂 Cybersécurité** : Notions, outils et bonnes pratiques en sécurité informatique.

### Gestion & Culture Professionnelle
* **📂 SUPERVISION** : Outils et méthodes de monitoring de systèmes.
* **📂 UI-UX** : Principes de design d'interface et d'expérience utilisateur.
* **📂 Connaissance de l'entreprise** : Culture générale et gestion d'entreprise.
* **📂 Personal Branding** : Développement de la marque personnelle et de l'identité professionnelle.
* **📂 English** : Supports de cours et exercices pour l'anglais technique.
* **📂 Domotique** : Projets et cours liés à la maison connectée.

## 📖 Utilisation et Lecture

Ce dépôt est une ressource documentaire. Il ne nécessite aucune installation logicielle complexe.

1.  **Parcourir en ligne :** Vous pouvez naviguer directement à travers les dossiers et lire les documents (Markdowns, PDFs, codes sources) directement depuis l'interface GitHub.
2.  **Télécharger une archive :** Vous pouvez télécharger l'intégralité du dépôt au format `.zip` via le bouton "Code" -> "Download ZIP" en haut à droite de la page d'accueil du dépôt.
3.  **Cloner le dépôt :** Pour une copie locale synchronisée (si vous souhaitez modifier/ajouter vos propres notes), vous pouvez le cloner à l'aide de Git :
	```bash
    git clone https://github.com/TheotimALBERTEAU/COURS-B2.git
    ```
